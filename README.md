# India Weather (React + Vite)

Live weather for 190+ Indian cities, plus search for any other place in India.
Data: Open-Meteo (free, no API key).

## Run
    npm install
    npm run dev      # open the URL it prints (usually http://localhost:5173)

## Build for hosting
    npm run build    # output in dist/ (upload to Netlify, Vercel, GitHub Pages, etc.)
